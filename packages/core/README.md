# @mg/core

LLM の接続先と、道具の共通の部品を集めたパッケージです。

ハーネスは、ここにある型だけを見て作ります。
接続先やスキーマのライブラリを替えても、書き直しが要りません。

## 役割

core の役割は 3 つです。

- 接続先の共通の型を決めます。OpenRouter と ollama 向けの実装も持ちます。
- 動く道具の共通の型を決めます。
- 道具の呼び出しを 1 回分、検証して実行する部品を持ちます。

### 接続先

接続先は、LLM との 1 往復だけを担当します。
返し方は、一括と細切れの 2 通りです。
細切れのほうは、文章の断片などの出来事を順に返します。

OpenRouter との通信は、その実装の中に閉じています。
API キーは、接続先を作るときに受け取ります。

ollama との通信も、別の実装として持ちます。
ollama は鍵を確かめないため、鍵は受け取りません。

接続先の URL は省略できます。
省略したときは、手元で動く ollama に向きます。

次の指定も、接続先を作るときに渡せます。

- 読める文脈の長さです。
- 考える動作を使うかどうかです。
- モデルをメモリに残しておく時間です。

### 動く道具

動く道具は、LLM に見せる道具の形に実行関数を足したものです。
形を変えずに、そのまま接続先への要求に渡せます。

引数のスキーマには条件があります。
検証と JSON Schema への変換の両方ができるものに限ります。

作業場所や時間制限は、道具を作るときに渡します。

### 実行の部品

実行の部品は、道具の一覧と呼び出し要求を受け取ります。
名前で道具を探し、引数を検証してから実行します。
結果は、道具の結果を伝える発言として返します。

## やらないこと

次のことは core の外に任せます。

- 道具の実体は持ちません。組み込みの道具は tools に置きます。
- 道具の呼び出しの繰り返しはしません。ハーネスの仕事です。
- 子プロセスや環境変数など、環境に依存するコードを入れません。
- スキーマのライブラリには依存しません。使う側が持ち込みます。
- 接続先は、引数をスキーマで検証しません。実行の部品が行います。

## 構成

ソースは 2 つのフォルダに分かれます。

```
src/
├── providers/  接続先の型、エラー、OpenRouter と ollama の実装
└── tools/      動く道具の型、実行の部品、そのエラー
```

主な名前を、フォルダごとに並べます。

```
providers/
  Provider                  接続先の共通の型
  createOpenRouterProvider  OpenRouter の接続先を作る
  createOllamaProvider      ollama の接続先を作る
  readSseData               ストリーミングの応答を読む

tools/
  Tool, defineTool          動く道具の型と、定義の補助
  runToolCall               呼び出しを 1 回分、検証して実行する
```

## エラー

エラーは 2 つの系統に分かれます。
接続先の失敗と、道具の実行の失敗です。

系統ごとの名前をまとめます。

```
接続先のエラー
  ProviderBaseError       親（直接は作れない）
  ProviderHttpError       失敗の応答が返った
  ProviderTransportError  通信そのものが失敗した
  ToolArgumentsError      呼び出しの引数が読めない
  ToolSchemaError         スキーマを変換できない
  ProviderError           4 つの合併型
  isProviderError         絞り込み

道具の実行のエラー
  ToolRunBaseError        親（直接は作れない）
  ToolNotFoundError       その名前の道具がない
  ToolInputError          引数の検証に失敗した
  ToolRunError            2 つの合併型
  isToolRunError          絞り込み
```

包み方には、次の決まりがあります。

- 接続先のエラーは、元の例外を中に残します。
- 中断による停止は、包まずにそのまま通します。
- 道具の実行関数が投げた例外も、そのまま通します。
