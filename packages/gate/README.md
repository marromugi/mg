# @mg/gate

道具の呼び出しなどを、人に聞かずに実行してよいか判定する口のパッケージです。

## 役割

- 判定の口の型を決めます。
  受け取るのは、種類と説明文と元の値です。
  返すのは、可否と理由です。
- 方針の文章と接続先とモデルから、LLM で判定する実装を作れます。
- 判定そのものが失敗したときのための、専用の例外を持ちます。
- 道具の実行を包み、実行の前に判定を挟む口を持ちます。

### 型と実装の分け方

core の接続先と同じ考え方です。
判定の口は、入力と出力を型で固定します。

中身は差し替えられます。
最初の実装は、方針の文章を LLM に読ませて判定するものです。
規則だけで判定する実装も、同じ型で作れます。

型を固定することで、判定の口を付ける側は中身を知らずに済みます。
中身を差し替えても、付ける側の書き直しは要りません。

### LLM の実装

`createLlmGate` は、方針の文章と接続先とモデルを受け取ります。
受け取ったものから、判定の口を作ります。

判定するたびに、接続先へ 1 回だけ問い合わせます。
送るのはシステムの指示と方針の文章、それに判定したい内容です。
判定したい内容は、渡された説明文そのままです。

答えの形は、判定専用の道具の呼び出しを強制して固定します。
道具から返った値を検証し、可否と理由に変えます。

### 道具の実行に付ける口

`gateRunToolCall` は、道具を実行する部品を受け取り、
実行の前に判定を挟んだ部品を返します。

道具の呼び出しは、判定の入力に組み立てます。
種類は `tool-call` で、説明文には道具の名前と説明と引数を並べます。
元の値には、呼び出しと道具の定義（`execute` を除く）を入れます。

判定が「よい」なら、元の実行部品をそのまま呼びます。
「だめ」なら道具を動かさず、理由を道具の結果として返します。
判定そのものが失敗したときも、道具を動かさず、
失敗した旨を道具の結果として返します。
中断の合図だけは、包まずにそのまま投げ直します。

## やらないこと

- 判定を記録には残しません。
- ハーネスのループや runner への組み込みは持ちません。
- 記録を見る画面には手を入れません。
- 規則だけで判定する実装は、まだ持ちません。

## 使い方

`createLlmGate` に渡すものを表にまとめます。

| 名前       | 内容                       |
| ---------- | -------------------------- |
| `provider` | 使う接続先                 |
| `model`    | 使うモデルの名前           |
| `policy`   | 判定の根拠にする方針の文章 |

```ts
import { createLlmGate } from "@mg/gate";

const gate = createLlmGate({
  provider,
  model: "openai/gpt-4o-mini",
  policy: "読み取り専用のコマンドだけ、聞かずに実行してよい。",
});

const verdict = await gate.judge({
  kind: "tool-call",
  description: "Runs `bash` with command: rm -rf /",
});

// verdict は { allowed: boolean, reason: string }
```

判定そのものが失敗すると、`GateError` を投げます。
元の例外は `cause` に残ります。

中断の合図だけは、包まずにそのまま通します。
`context.signal` に中断済みの合図を渡すと、接続先を呼ばずに投げます。

`gateRunToolCall` は、判定の口と、実行部品を受け取ります。
実行部品を省くと `@mg/core` の `runToolCall` を使います。

```ts
import { gateRunToolCall } from "@mg/gate";

const runToolCall = gateRunToolCall(gate);

const message = await runToolCall(tools, call, context);
// 判定が「だめ」なら、tools と call は実行されない
```
