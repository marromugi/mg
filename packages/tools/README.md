# @mg/tools

ハーネスが共通で使う、組み込みの道具を集めたパッケージです。

## 役割

- 組み込みの道具の実体を持ちます。
- どの道具も、core の道具の型で作ります。core の実行の部品にそのまま渡せます。
- 引数のスキーマは zod で書きます。スキーマの実装を持つのはここだけです。
- 子プロセスなど、環境に依存するコードはここに閉じます。
- 作業場所や時間制限は、道具を作るときに受け取ります。

## やらないこと

- 接続先とはやり取りしません。LLM との通信は core の仕事です。
- 道具の呼び出しの繰り返しはしません。ハーネスの仕事です。

## 道具の一覧

いま入っている道具を表にまとめます。

| 道具         | すること                        | オプション        |
| ------------ | ------------------------------- | ----------------- |
| `bash`       | シェルでコマンドを 1 つ実行する | 作業場所など 4 つ |
| `web_search` | 検索の口を使って Web を検索する | 検索の口など 3 つ |

### bash

LLM から受け取る引数は、コマンドの文字列 1 つです。

作るときのオプションは 4 つです。
作業場所だけは必須です。
ほかは省くと、例に書いた値になります。

```ts
createBashTool({
  cwd: "/path/to/work", // 作業場所
  timeoutMs: 30000, // 時間制限（ミリ秒）
  shell: "/bin/sh", // 使うシェル
  maxOutputBytes: 1048576, // 出力の上限（バイト）
});
```

結果は 1 つの文字列にまとめて返します。

- 標準出力と標準エラーと終了コードを含めます。
- 終了コードが 0 以外でも、例外は投げません。
- 時間切れでも投げません。その旨を結果に書きます。
- 出力が上限を超えたら、切り詰めてその旨を付けます。
- 中断の合図で止めたときは、例外をそのまま通します。

### web_search

Web を検索する道具です。実際に検索する処理は持ちません。

検索する処理は「口」と呼ぶ部品に任せます。
口は、語句と件数の上限を受け取り、題名と URL と断片の一覧を返します。

```ts
type WebSearchBackend = {
  name: string;
  search(
    request: { query: string; maxResults: number },
    context: { signal?: AbortSignal },
  ): Promise<{ title: string; url: string; snippet: string }[]>;
};
```

LLM から受け取る引数は、検索したい語句の文字列 1 つです。

作るときのオプションは 3 つです。
検索する口だけは必須です。
ほかは省くと、例に書いた値になります。

```ts
createWebSearchTool({
  backend: myBackend, // 検索する口
  maxResults: 5, // 返す件数の上限
  maxSnippetChars: 500, // 断片の文字数の上限
});
```

結果は 1 つの文章にまとめて返します。

- 題名と URL と断片を、番号付きで結果ごとに並べます。
- 断片は改行や連続する空白を 1 つにまとめてから、上限の文字数で切ります。
- 切ったところには「…」を付けます。
- 口が返した件数が上限より多くても、道具の側で上限まで切ります。
- 結果が 0 件なら、その旨を文章で返します。

口が失敗したときは、その例外をそのまま通します。
道具は口の例外を包みません。

口の実装は、検索の失敗を表す専用の例外を投げられます。

```ts
new WebSearchError("失敗の説明", { cause: 元の例外 });
```

#### Ollama の口

Ollama の検索 API を使う口です。手元の Ollama ではなく、ollama.com のサーバーと通信します。

鍵は ollama.com の無料のアカウントで作れます。

```ts
createOllamaWebSearchBackend({
  apiKey: "your-api-key", // ollama.com の鍵
  baseUrl: "https://ollama.com", // 接続先。省くとこの値になります
  headers: {}, // 追加で送るヘッダー
  fetch: globalThis.fetch, // 通信に使う関数
});
```

鍵だけが必須です。ほかは省くと、例に書いた値になります。

| オプション | 必須   | すること                    |
| ---------- | ------ | --------------------------- |
| `apiKey`   | 必須   | ollama.com の鍵を渡します   |
| `baseUrl`  | 省略可 | 接続先の URL を差し替えます |
| `headers`  | 省略可 | 送るヘッダーを追加します    |
| `fetch`    | 省略可 | 通信する関数を差し替えます  |

この口を `web_search` の道具と組み合わせて使います。

```ts
createWebSearchTool({
  backend: createOllamaWebSearchBackend({ apiKey: "your-api-key" }),
});
```

Ollama の検索 API は、1 回の検索で返す件数が 10 件までに決まっています。
`maxResults` にそれより大きい値を渡しても、10 件までしか返りません。
